My First Python Coding Project

The project is a menu-based python program with 4 useful mini tools built.
Included features are:
 1.Grade Calculator: that converts scored to letter grades.
 2.To-Do LIst: that adds and view tasks.
 3.Number Guessing Game: Guess 1-10 with hints.
 4.Even/Odd Checkers: Checks if numbers are even or odd.

The following list is the python concepts i used:

-Variables and data types
-User input/output
-Type Casting
-Operators
-If/Elif/Else
-Loops
-Functions
-Lists
-Modules

Here are the steps to run the program:
1.Clone repo: git clone https://github.com/Sibongilewm9/Python-mini-toolkit.git
2.Run 'main.py'
3.Choose tools from the menu.
